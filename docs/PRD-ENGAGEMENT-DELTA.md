# 薪慰互动迭代

本次增量以 [完整交接规格](iteration-engagement/CODEX_ITERATION_PROMPT.md) 为准。以下约定替代 PRD 1.1 的自动展示、整月回算、舍入和无每日记录条款。

| 用户操作 | 保存的事实与展示 |
| --- | --- |
| 打开小窗 | 等待开工。首次使用之前的日期不生成记录。 |
| 开工 | 保存一次当天开工、当日作息区间、月计划秒数、工资和扣减规则。展示截至当前的计划内累积。 |
| 晚来 | 默认免费。按分钟时，从已过的计划工作秒数中扣掉宽限，剩余秒数向上取整为计费分钟。扣减仅在首次开工时确定。 |
| 收工或继续 | 收工后冻结金额，晚收工只记时长。当天继续沿用原快照与首次扣减。 |
| 跨日未收尾 | 计划内进度封顶，结束时间待确认。可以先开启新的一天。 |
| 回归与补算 | 允许跳过近况。只补用户确认的本月计划日，按当前设置估算，可按批次撤销。 |
| 修改设置 | 已有记录保留快照，新规则用于下一个未开启的日期。本月摘要仅累计有记录的日期。 |

金额以整数分乘工作秒数，先减去扣减的精确分子，再除以月计划秒数，最终向零截断。例：月薪 ¥16,800、月计划 168 小时，09:10 开工的默认估算为 ¥16.66。每分钟扣 ¥1 时，记录扣减 ¥10.00，净估算为 ¥6.66。午休不累计，18:00 后计划内金额封顶。

数据存放在本机原有配置及备份中。旧配置首次进入时建立空的互动记录。Windows 的写入沿用互斥锁、版本检查、原子替换和保存后广播。每个窗口只展示自己成功提交的事件。日状态、动作键、事件与已选文案分别记录，金额遮罩也应用于插值文案。

正式美术仍待交付。动作及替换要求见[角色素材规格](iteration-engagement/assets/MASCOT_ASSET_SPEC.md)。
