# 薪慰统一视觉系统

版本：1.0，2026年11月4日。

## 风格与范围

采用轻幽默编辑式桌面视觉：干净的黑白基础、荧光黄绿色强调、一个原创线描角色、少量手绘下划线。图2提供组件秩序，图3提供品牌细节，图1提供深色层级。三图中的工作台、历史月份选择及示例错误不纳入实现。

界面保持“小窗＋设置”。本轮复用现有计薪、隐私、持久化和桌面命令；没有引入第二套计薪逻辑或大型UI框架。打卡、迟到、加班互动待后续需求稿明确后实施。

## 色彩

所有界面颜色集中在 `src/styles/tokens.css`。

| 语义 | 浅色 | 深色 |
| --- | --- | --- |
| 画布 | #F6F5F0 | #151617 |
| 表面 | #FFFFFF | #222426 |
| 次级表面 | #ECECE7 | #2B2E30 |
| 主文字 | #202321 | #F5F5F0 |
| 次要文字 | #686D69 | #A7ADA8 |
| 普通边框 | #DADDD6 | #3A3E3B |
| 品牌强调 | #D8FA57 | #D8FA57 |
| 辅助紫 | #C8B5F5 | #C8B5F5 |

主按钮、当前导航、工作状态和工作进度使用品牌强调色，均配深色文字。午休使用紫色标签和进度；休息日使用低饱和蓝色；已下班及上班前使用中性灰；错误使用红色。每种状态都配文字，不只依赖颜色。

基于实际Token计算的颜色对比值：浅色主文字/白底15.86，浅色次要文字/画布4.83，深色主文字/表面14.24，深色次要文字/表面6.81，品牌按钮文字/背景13.39。这是颜色组合的数值检查，不代表完整无障碍认证。

## 字体与尺寸

使用系统字体栈：Segoe UI、Microsoft YaHei UI、PingFang SC、sans-serif。不下载远程字体。金额启用tabular-nums，使用统一格式化与遮蔽函数。

| 内容 | 字号 |
| --- | --- |
| 小窗主金额 | 38px；长金额28px |
| 设置主标题 | 26px |
| 设置卡片标题 | 15px |
| 表单及正文 | 13px；说明段落12px |
| 状态与辅助文字 | 11px |
| 小窗短句、次要标注 | 10px |

间距以4/8px为基础，常用12、16、20、24、32px。圆角：按钮10px、输入8px、设置卡片14px、网页小窗18px。深色主要靠表面亮度区分层级，不堆叠重阴影。

## 小窗

实现尺寸为 **280×180逻辑像素**。相对prompt的280×150增高30px，用于保留38px金额、清楚的状态和必要操作；不会将概念板整体缩小或压成微型文字。

固定顺序：品牌与更多菜单、今日已赚、主金额、状态与今日进度、进度条、短句。月度金额在设置页查看，速率不常驻小窗。长金额自动减少字号并隐藏角色，完整保留整数和小数。

更多菜单包含金额隐藏、置顶、设置、隐藏小窗、退出。顶部操作区域28px，菜单行高26px；五项操作能在小窗内完整展开。菜单在短窗口内有溢出保护。

Windows原生窗口采用不透明表面，外轮廓由系统管理；本轮不引入透明窗口能力。网页预览的18px外轮廓不作为Windows圆角已通过实机验收的证明。

## 设置

原生窗口初始620×740，最小宽度540。使用132px简洁侧栏，只有工资与作息、本月日历、桌面偏好、关于四组。

表单区域独立滚动；工资及日历编辑时，底部68px操作栏固定显示，滚动区域减去操作栏高度，避免遮挡输入。日历同时显示“班/休”和颜色，日期覆盖另有标记。

工资、作息和日期覆盖先保留草稿，再预览今日、本月、天数和时长的前后差异，最后提交。错误显示在字段附近，保存失败保留草稿；用户看到的是中文错误，不包含Error前缀。

## 共享组件与资源

- `SalaryAmount.vue`：可见及隐私金额、等宽数字、长金额。
- `money.ts`：所有界面共用的金额遮蔽规则，固定六个圆点。
- `WorkStatusBadge.vue`：状态文字、状态点与语义色。
- `ProgressIndicator.vue`：进度、边界钳制及可访问名称。
- `BrandIllustration.vue`：统一引用品牌母版。
- `src/assets/mascot-work.svg`：原创本地线描角色，白色圆润身体、黑线、电脑和少量强调线。

原生图标与托盘图标也从同一个SVG导出。角色不是概念板的原始素材，不宣称逐像素复刻；其形态是按用户允许的可维护本地SVG方向重新绘制。

首版只展示一个工作角色，午休、休息和异常态可不展示插画。每个小窗最多一个角色与一种轻装饰。手绘下划线只用于设置侧栏短句，不穿过金额。

## 深浅模式

正式应用跟随系统。`data-theme`支持开发态对照和截图，不作为持久化用户主题选择。手动浅色/深色/系统选择与冻结PRD存在差异，本轮未扩展配置模型，待需求确认后增加。

## 演示与实际数据

开发态 `?preview=working` 使用2026年11月3日14:30、月薪16800元、21天/168小时。金额450.00/1250.00及56.25%均由同一个domain计算。

`src/dev/preview.ts`仅在开发构建加载。演示通过独立内存配置，不读写个人工资或正式配置文件；生产构建排除固定时间和故障注入代码。实际应用仍读取真实时间。

## 交互与动效

按钮具有默认、悬停、按下、禁用、焦点及保存中状态。输入保留原始编辑文本，校验后再生成规则。状态不带播放三角，不要求手动点击开始计时。

过渡控制在150—200ms；不持续播放角色动画。遵守prefers-reduced-motion，窗口不可见时不更新无用动画。接下来新的打卡需求将单独改变计时入口，本视觉版本不提前实现。
